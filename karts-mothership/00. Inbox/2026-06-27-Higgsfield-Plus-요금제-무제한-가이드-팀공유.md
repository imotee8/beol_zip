# 힉스필드 Plus 요금제 — 무제한 / 크레딧 가이드 (팀 공유)

> **결론 먼저:** 영상은 **Kling 무제한**으로 마구 돌리고, **Seedance는 크레딧 차감**이니 최종 퀄만 뽑는다. 무제한은 **반드시 `higgsfield.ai` 웹에서** 써야 적용된다.

## 플랜 요약

| 항목 | 내용 |
|---|---|
| 플랜 | **Plus** |
| 가격 | 월 $59 / **연 $47** (연 결제 시 $144 절약) |
| 크레딧 | **1,200 크레딧 / 월** (이월 안 됨) |
| 동시 생성 | 영상 6개 · 이미지 8개 |
| 접근 | 모든 모델·기능, Supercomputer, 모든 Seedance 모델 |

---

## 🟢 무제한 — 크레딧 안 깎임

| 모델 | 종류 | 조건 |
|---|---|---|
| **Kling 3.0** | 🎬 영상 | **완전 무제한** ← 영상 주력은 이걸로 |
| Nano Banana 2 | 🖼 이미지 | 2K 무제한 |
| Seedream 5.0 Lite | 🖼 이미지 | 365일 무제한 |
| Seedream 4.5 | 🖼 이미지 | 365일 무제한 |
| Flux.2 Pro (1K) | 🖼 이미지 | 365일 무제한 |
| Nano Banana | 🖼 이미지 | 365일 무제한 |
| Kling O1 Image | 🖼 이미지 | 365일 무제한 |
| GPT Image | 🖼 이미지 | 365일 무제한 |
| Soul V2 & Cinema | 🎨 스타일 | 무제한 아님 — **5,000장 무료** 제공 |

## 🔴 크레딧 차감 — 1,200에서 깎임

| 모델 | 종류 | 비고 |
|---|---|---|
| **Seedance 2.0 / 2.0 Mini / 2.0 Fast** | 🎬 영상 | full access·**4K 가능**이지만 **무제한 아님** |
| **Nano Banana Pro** | 🖼 이미지 | 약 **600장** 분량 |

> **크레딧 환산:** 1,200크레딧 = Nano Banana Pro 600장 ≈ Kling 137영상치.
> Kling은 무제한이므로 크레딧은 사실상 **Seedance · Nano Banana Pro 쓸 때만** 닳는다.

---

## ⚠️ 팀이 꼭 알아야 할 함정 2개

1. **무제한은 `higgsfield.ai` 웹에서만 적용.**
   포토샵 플러그인 / MCP·CLI / Supercomputer / Canvas에서 돌리면 **무제한 모델이라도 크레딧 차감.**
   → Kling 무제한 뽕 뽑으려면 **웹에서** 돌릴 것.

2. **Seedance는 크레딧 관리 필요.**
   Seedance는 무제한이 아니라 1,200크레딧 한도 안에서 소모. 막 돌리면 월말에 고갈.
   → **이터레이션은 Kling(무제한), 최종 퀄만 Seedance** 전략이 크레딧상 유리.

## 🎯 팀 운용 권장

| 단계 | 쓸 모델 | 이유 |
|---|---|---|
| 영상 이터레이션·테스트 | **Kling 3.0 (웹)** | 무제한, 마음껏 |
| 이미지 컨셉·키프레임 | Seedream / Flux.2 / Nano Banana (웹) | 무제한 |
| 최종 고퀄 영상 | **Seedance 2.0 (4K)** | 크레딧 차감 → 확정본만 |
| 고퀄 이미지 마무리 | Nano Banana Pro | 크레딧 차감 → 600장 한도 |

> 하나의 공유 계정 기준. 크레딧이 자주 모자라면 **Ultra(연 $99)** 또는 **Team(연 $65/seat, 2~9인 공유 크레딧풀)** 전환 검토.
